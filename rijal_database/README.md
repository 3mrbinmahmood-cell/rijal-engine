# قاعدة مصادر الرجال — الإصدار 1.0

قاعدة محلية مستقلة، أُعدت لتتصل بقارئ الشاملة. تحتوي على نصوص مجموعة المصادر المرفوعة، مع البحث والفهارس ومواضع الصفحات وإحالات كل نتيجة. لا تحتاج إلى اتصال بالإنترنت أثناء البحث.

## التشغيل على Windows

1. نزّل جميع أجزاء ZIP وأبقها معًا. فك ضغط الجزء الأول وافتح مجلد `rijal_database`؛ يستطيع المشغل قراءة بقية أجزاء ZIP المجاورة للمجلد أو الموجودة في المجلد الأعلى منه. ويمكن بدلًا من ذلك فك ضغط جميع الأجزاء في الوجهة نفسها لدمج محتويات `rijal_database`.
2. يلزم وجود Python 3.10 أو أحدث مع SQLite/FTS5. لا تحتاج القاعدة الجاهزة إلى حزم Python إضافية.
3. افتح `START_WINDOWS.bat`. في التشغيل الأول تتحقق الأداة من أجزاء القاعدة وتفك ضغطها تلقائيًا إلى `rijal.sqlite`؛ انتظر اكتمال ذلك. ستفتح صفحة البحث تلقائيًا. أبق نافذة التشغيل مفتوحة أثناء الاستعمال.
4. إن لم تفتح الصفحة، افتح `http://127.0.0.1:8765/` في متصفحك.

على Linux أو macOS: شغّل `python3 launch.py --open` من مجلد الحزمة.

لمنفذ بديل: `python launch.py --port 8767 --open`، ثم غيّر عنوان الخدمة في إعداد ربط القارئ.

## ربطها بالقارئ

هذا إصدار قاعدة بيانات، وليس استبدالًا للقارئ القديم. ملفات القارئ الأصلي وملاحظاته وتظليلاته لم تتغير. أُرفق محول اختياري، واختُبر مع نسخة V0.5.5 التي قدمتها.

لإضافة زر «قاعدة الرجال الموسعة» إلى نسختك من القارئ:

1. صدّر نسخة احتياطية من ملاحظات القارئ بالطريقة المعتادة قبل تحرير ملفاته.
2. انسخ الملفين `reader_adapter/rijal-db-client.js` و`reader_adapter/rijal-db-button.js` إلى مجلد القارئ، بجوار `index.html`.
3. أضف السطرين الآتيين قبل `</body>` في ملف `index.html` الخاص بالقارئ:

```html
<script src="rijal-db-client.js"></script>
<script src="rijal-db-button.js"></script>
```

4. شغّل القاعدة، وافتح القارئ من موضعه وطريقته المعتادة. لا تنقله إلى عنوان جديد؛ تخزين المتصفح مرتبط بعنوان القارئ.
5. حدد اسمًا في نص القارئ، ثم اضغط الزر الجديد. تُفتح نافذة البحث داخل القارئ مع الاسم المحدد. يمكن فتحها أيضًا دون تحديد نص.

المحول لا يكتب في `localStorage`، ولا يبدل `SHAMELA_DATA` أو فهرس الرجال القديم، ولا يغيّر تحليل السند القديم. واجهة API مستقلة ومهيأة للقارئ القادم؛ راجع `API.md`.

## ما الذي حُفظ؟

- كل ملف مصدر له بصمة SHA-256، واسم ملف أصلي، وموضع داخل ZIP، وبيانات الكتاب المتاحة.
- كل موضع صفحة له معرف ثابت ومرجع الكتاب والجزء ورقم الصفحة المطبوع إن وُجد. إذا لم يوجد رقم مطبوع، نعرض ترتيب الموضع مع التنبيه إلى غياب الرقم.
- النص المستخرج يحتفظ بالألفاظ والتشكيل والمحارف غير المرئية والحواشي. أضيفت فواصل أسطر بنيوية لتمثيل الفقرات والعناوين في النص القابل للبحث. فك ترميز HTML وتحويل بنيته إلى نص ليس نسخة بايتية من HTML؛ الأصل محفوظ في الأرشيف دون تغيير.
- رؤوس الصفحات وأرقامها محفوظة في حقول مستقلة؛ لا تُدخل ضمن نص الصفحة المستخدم لاكتشاف التكرار.
- الإحالات تحدد المصدر والصفحة والموضع الحرفي. مواضع الأحرف محسوبة بنقاط Unicode، وليست بوحدات UTF-16 الخاصة بـ JavaScript.

احتفظ بأرشيفك الأصلي `Rijaal database data raw.zip` دون تعديل. لم نكرر هذا الأرشيف الكبير داخل حزمة القاعدة. النصوص والبحث والمراجع متاحة بدونه؛ ولتنزيل ملفات HTML الأصلية من الواجهة ضع نسخة منه في مجلد `sources/`. تُفحص بصمة ملف HTML قبل تقديمه. توجد بصمة الأرشيف وجميع ملفاته في `reports/SOURCE_MANIFEST.json`.

## إزالة التكرار

- تُكتشف الملفات المتطابقة بالبايتات، مع بقاء كل موضع مصدر.
- نص الصفحة المتطابق يخزن ويُفهرس مرة واحدة، وتبقى جميع مواضعه وروابطه. البحث في النصوص يعرض هذه المواضع مجمعة.
- الفقرات ذات 80 محرفًا فأكثر تفهرس للتطابق الحرفي، مع حفظ جميع مواضعها وإزاحاتها. لا يُحذف النص من صفحات المصادر.
- الفقرات المتساوية بعد تطبيع البحث تُسجل كاختلافات تحتاج إلى مراجعة، ولا تُدمج ألفاظها. راجع `reports/NORMALIZATION_VARIANTS.csv`.
- لا يجري هذا الإصدار إزالة تكرار دلالية شاملة، ولا توحيد هويات الأشخاص آليًا. اختلاف الألفاظ والمعلومات والأحكام باقٍ. تكرار قول في كتب متعددة لا يثبت استقلال طرق نقله.

## البحث

- «جميع الكلمات»: وجود جميع كلمات الاستعلام، دون اشتراط الترتيب.
- «عبارة مرتبة»: الكلمات متجاورة بالترتيب بعد التطبيع.
- «مطابقة حرفية»: وجود المحارف نفسها، بما فيها التشكيل والمسافات، داخل نص الصفحة المستخرج.
- «بداية الكلمة الأخيرة»: يسمح بتكملة الكلمة الأخيرة.
- البحث المرن يتجاهل الحركات والتطويل والمحارف التنسيقية، ويقرب أشكال الألف والياء وكتابة ابن/بن. لا يمثل بحثًا صرفيًا أو بالجذور أو بالمعنى، ولا يحل جميع الكنى والاختصارات.
- يمكن البحث في كل النصوص أو في العناوين والمداخل المرشحة، مع التصفية بحسب مجموعة المصدر.
- ترتيب نتائج النصوص مبني على مطابقة البحث، لا على ترجيح علمي بين الكتب.

## حدود الاستخراج الآلي

العناوين والمداخل المرشحة ليست عددًا للأشخاص المحققين؛ قد تشمل فهارس وعناوين عامة أو مدخلًا غير مكتمل. لا نفترض أن الصفحة التالية تنتمي إلى الشخص نفسه بلا دليل. واجهة المدخل تعرض مقطع الصفحة الحالية وتتيح متابعة المصدر.

عبارات «روى عن» و«روى عنه» و«سمع من» وإشارات القرابة محفوظة بوصفها إشارات نصية غير محسومة. ارتباط الإشارة بأقرب مدخل سابق في الصفحة مجرد اقتراح سياقي؛ قد تتعلق الإشارة بشخص آخر. لا يُستنتج من غياب عبارةٍ انقطاعُ سند، ولا تُعطى أحكام آلية على صحة الأحاديث.

توجد جداول للهويات والأسماء البديلة والأقوال الموثقة وروابط المراجعة، وهي فارغة حتى إجراء تحقيق مستند إلى الأدلة. لا تُنشأ أحكام مختصرة من نصوص طويلة بما قد يسقط قيدًا أو خلافًا.

## التحديث وإعادة البناء

أوقف الخدمة قبل استيراد مصادر أو تشغيل تدقيق يكتب في القاعدة. احتفظ بنسخة احتياطية من القاعدة قبل تحديثها. تتطلب أدوات الاستيراد مكتبة `lxml` (الإصدار المستخدم مسجل في `requirements-import.txt`)؛ الخدمة والبحث في القاعدة الجاهزة لا يتطلبانها.

```text
python tools/import_sources.py "Rijaal database data raw.zip"
python tools/audit_database.py "Rijaal database data raw.zip"
python -m unittest discover -s tests -v
```

إعادة استيراد الأرشيف نفسه لا تضاعف السجلات. تغيير الأرشيف ينشئ مجموعة مصادر جديدة تحفظ النسخة السابقة؛ لا تُستبدل النسخ القديمة بصمت. تُجمع النصوص المتطابقة بين الدفعات مع حفظ إحالاتها. المعرفات ثابتة لإعادة استيراد الأرشيف نفسه، ولا تمثل هوية شخص ثابتة بين طبعات مختلفة.

## الملفات المهمة

| الملف | الغرض |
|---|---|
| `rijal.sqlite` | القاعدة الكاملة والفهارس |
| `server.py` | خدمة البحث المحلية للقراءة فقط |
| `reader_adapter/` | محول القارئ وملفات الربط |
| `schema.sql` | بنية القاعدة |
| `reports/AUDIT.json` | أعداد السجلات ونتائج التحقق وقياس البحث |
| `reports/BOOK_INVENTORY.csv` | جرد مجموعات المصادر والصفحات |
| `reports/SOURCE_MANIFEST.json` | بصمات الأرشيف وملفات المصادر |
| `reports/NORMALIZATION_VARIANTS.csv` | مجموعات تشابه مطبّع تحتاج إلى مراجعة |
| `tests/` | اختبارات المحافظة على النص والمراجع وإعادة الاستيراد |

يمكن نسخ المجلد إلى جهاز آخر. لا يحتاج الاستعمال المحلي إلى حساب أو خدمة خارجية. الخدمة ترتبط بعنوان الجهاز المحلي `127.0.0.1` فقط.

## الإحصاءات الزمنية

افتح «إحصاءات التراجم وفترات ٣٠ و١٠٠ سنة» من صفحة البحث. يبدأ التقسيم بـ١–٣٠ و١–١٠٠ هـ. الأساس سنة الوفاة، لا سنة الميلاد. الأعداد لمجموعات أولية تتفق في الاسم المستخرج وسنة الوفاة، وليست تعدادًا محققًا للأشخاص. تشمل المصادر تراجم عامة إلى جانب رواة الحديث. تبقى السنوات القصيرة التي لا يتضح قرنها، والتواريخ التقريبية والمتعارضة والميلادية فقط، خارج الجدول، مع بيان عددها. كل تاريخ مستخرج مرتبط بعبارته ومرجعه في `reports/CHRONOLOGY_EVIDENCE.csv`، ويحتفظ التقرير بالتمييز بين التقويم الهجري المصرح به والمفترض من سياق الوفاة.
