# قاعدة الرجال — المرحلة الثالثة: استخراج التراجم والعبارات

هذا تحديث مستقل لقاعدة V1، وفق التسلسل: حفظ المصادر وفهرستها ← إتاحة النص للبحث ← استخراج التراجم والعبارات ← مراجعة الهويات والتكرار ← الدمج مع القارئ.

## التشغيل

1. ثبّت وشغّل قاعدة الرجال V1 أولًا، واترك ملفاتها في مجلد `rijal_database`.
2. فك ملف التحديث بجوار المجلد بحيث تندمج محتويات مجلد `rijal_database` الجديد مع القديم. إن كان التحديث في عدة أجزاء، احتفظ بها معًا وفك الجزء الأول؛ يستطيع المشغّل قراءة الأجزاء الباقية المجاورة له.
3. افتح `START_EXTRACTION_WINDOWS.bat`. على Linux/macOS شغّل `sh start_extraction.sh`.
4. تفتح واجهة الفحص على `http://127.0.0.1:8766/`. يلزم Python 3.10 أو أحدث. تحتاج أول مرة إلى فحص قاعدة V1 وفك قاعدة الاستخراج.

يحفظ التحديث ملف `extraction.sqlite` مستقلًا. لا يبدّل نصوص V1، ولا يتصل بمخزن ملاحظات القارئ، ولا ينشئ دمجًا لهويات الرجال. الرقم الذي يظهر في الواجهة هو عدد المداخل المرشحة أو مواضع العبارات، وليس عدد الأشخاص المختلفين.

## ما الذي استُخرج؟

- احتُفظ بجميع مداخل الأسماء المرشحة في V1. بعض المداخل تراجم، وبعضها إحالات قصيرة أو بيانات فهرسة؛ تُعرض تسميتها الآلية صراحة.
- تُلحق الصفحات التالية بالمدخل حتى أول عنوان مسجل تالٍ. يشمل ذلك العناوين غير المتعلقة بالأشخاص. لا يتجاوز الاستمرار حدود ملف HTML واحد. هذه حدود مرشحة، وقد تكون الترجمة الحقيقية أطول أو تتضمن عناوين داخلية.
- تُستخرج مقتطفات حرفية حول ألفاظ المولد، والوفاة، والشيوخ، والتلاميذ، والتقييم، والأسماء والكنى، والقرابة، والإحالات. الكلمات الدالة وحدها لا تكفي للحكم بأن الكلام يخص صاحب الترجمة.
- تفصل حواشي المحقق عن المتن. تبقى العبارات خارج التراجم متاحة مع تنبيه بأنها غير منسوبة إلى صاحب ترجمة محدد.
- يظهر لفظ القائل عند إمكان استخراجه من صيغة «قال فلان»، مع بقاء هويته غير محسومة. وقد تكون العبارة نقلًا مركبًا أو متعلقة بغير صاحب الترجمة.
- لا تمثل قائمة ألفاظ التقييم نظامًا كاملًا لتصنيف الحديث. تُعلّم بعض عبارات الحديث والإسناد بعلامة خاصة، وقد تفوت القاعدة حالات أخرى؛ يجب قراءة السياق.
- يُخزّن نص المقتطف المتطابق مرة واحدة مع إبقاء كل موضع، ونوع، وإحداثيات، ومرجع. هذا اشتراك في النص، وليس دمجًا للمعنى أو للقائل أو للمقصود.

## المراجعة والمراجع

يمكن البحث في أسماء التراجم أو ألفاظ المقتطفات، وتحديد نوع العبارة والمتن/الحاشية، وفتح سياق الترجمة وصفحة المصدر. الإحداثيات بوحدات محارف Unicode، وليست بايتات ولا وحدات UTF-16.

هذه واجهة فحص للمرحلة الثالثة. لا تحتوي على زر اعتماد هوية؛ مراجعة روابط الهويات والتكرار هي المرحلة التالية. لم تُغيّر جداول الوفيات في V1؛ تحويل عبارات الوفاة الجديدة إلى تواريخ منسوبة لأشخاص يحتاج إلى خطوة مستقلة.

## API محلي للمرحلة التالية

- `GET /api/stats`
- `GET /api/biographies?q=...&offset=0&limit=30`
- `GET /api/biography/ENTRY_ID?offset=0&limit=12`
- `GET /api/statements?q=...&kind=assessment&origin=main_text&bio=ENTRY_ID&offset=0&limit=30`
- `GET /api/page/PAGE_ID`

الأنواع: `birth`, `death`, `teachers`, `students`, `assessment`, `alias`, `family`, `cross_reference`.

تُحفظ الشفرة، واختبارات الحدود والمراجع، ونتائج التدقيق في التحديث. واجهة الفحص للقراءة فقط. التحقق الآلي لا يحل محل المراجعة العلمية، ولم يُجرَ تحقق بصري في متصفح حقيقي ضمن بيئة البناء.
